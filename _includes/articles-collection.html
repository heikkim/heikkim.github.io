{% comment %} A page that lists the articles of one category or one tag. The headline is the name of the category or the tag and the text under it is its description. Both come from the sitetext, where the categories are a list of entries with a slug, a label and a description, so the page files stay thin and a new category needs only a new page and a new entry. Without a category and without a tag it is the root of the articles, the Insights page, and it lists every article of the language. Parameters: - lang: the language of the articles, "fi" by default - category: the slug of a category, e.g. "leadership" - tag: the slug of a tag, e.g. "getting-off-the-ground-with-ai" {% endcomment %} {% assign lang = include.lang | default: "fi" %} {% assign curlang = site.languages | where: "code", lang | first %} {% assign postsText = site.data.sitetext.posts %} {% if curlang.locale and curlang.locale != "" and curlang.locale != nil %} {% assign postsText = site.data.sitetext[curlang.locale].posts %} {% endif %} {% if include.category %} {% assign collectionEntry = postsText.categories | where: "slug", include.category | first %} {% assign collectionTitle = collectionEntry.label | default: include.category %} {% assign collectionDescription = collectionEntry.desc %} {% elsif include.tag %} {% assign collectionEntry = postsText.tags | where: "slug", include.tag | first %} {% assign collectionTitle = collectionEntry.label | default: include.tag %} {% assign collectionDescription = collectionEntry.desc %} {% else %} {% comment %} The root of the articles, the Insights page {% endcomment %} {% assign collectionTitle = postsText.title %} {% assign collectionDescription = postsText.text %} {% endif %}
